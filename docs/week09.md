# Неделя 9: DeFi на Solana

**Задание:** изучить реальные протоколы экосистемы и интегрировать DeFi-функциональность в приложение.

## Изученные протоколы

| Протокол | Что делает | Как используется в Tip Jar |
|---|---|---|
| **Jupiter** | Агрегатор обменов: ищет лучший маршрут через DEX (Raydium, Orca, Meteora и др.) | Quote: сколько USDC можно получить за сумму чаевых |
| **Pyth Network** | Оракул цен: публикует цены активов on-chain и через Hermes API | Цена SOL/USD для показа стоимости чаевых в долларах |

## Что добавлено в приложение

- Панель **DeFi tools** (`web/src/Defi.tsx`).
- Живая цена SOL/USD из Pyth, обновляется каждые 30 секунд.
- Подсказка «чаевые стоят примерно $X».
- Кнопка **Tip this many USD in SOL**: вводишь сумму в долларах, поле чаевых заполняется в SOL по курсу оракула.
- Кнопка **Jupiter quote**: показывает, сколько USDC дадут за чаевые, влияние на цену и маршрут.
- Код вызовов API: `web/src/lib/defi.ts`.

## Важные ограничения (написать в отчёте)

- Мы работаем в **Devnet**, а у Jupiter и Pyth реальные данные и ликвидность на **mainnet**.
  Поэтому quote и цена читаются только для чтения, а сам swap приложение не выполняет.
- Адреса API и API-ключи вынесены в `web/.env` (см. `web/.env.example`): у обоих сервисов
  правила доступа менялись, и актуальные условия нужно смотреть в их документации
  (developers.jup.ag и docs.pyth.network). Если запрос вернёт 401, получи бесплатный
  ключ и впиши его в `.env`.
- Цену оракула нельзя считать безопасной для расчётов в контракте без проверки свежести
  (`publish_time`) и доверительного интервала (`conf`). Здесь она только для отображения.

## Как проверить

```bash
cd web
cp .env.example .env
npm install
npm run dev
```
Открой приложение, в блоке DeFi tools должна появиться цена SOL. Нажми Jupiter quote и
сделай скриншот.
